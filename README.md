# ESafe Tech — Company Website

A React.js marketing site for ESafe Tech, focused on software development and AI.

## Getting started

```bash
npm install
npm run dev
```

Open [http://127.0.0.1:5173](http://127.0.0.1:5173) in your browser.

## Project structure

```
src/
  components/   — Shared UI (Navbar, Hero, cards, effects)
  pages/        — Home, Services, Products, Company, Contact
  styles/       — Page and effect stylesheets
public/
  favicon.ico
  images/
```

## Assets

Images live in `public/images/`:

| File | Used in |
|------|---------|
| `logo-mark.png` | Navbar logo |

## Build for production

```bash
npm run build
npm run preview
```
